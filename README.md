# MemoWire
DFIR-приложение для автоматизированного анализа дампов памяти, образов дисков и логов. Запускает инструменты исследования, извлекает артефакты и объединяет результаты. Встроенный ИИ-ассистент помогает находить следы атак и нужные сведения через чат, объясняет находки и формирует ответы в заданном пользователем формате
